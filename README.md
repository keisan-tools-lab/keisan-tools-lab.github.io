Google AdSense 用の `ads.txt` を、ドメインのいちばん上（https://keisan-tools-lab.github.io/ads.txt）に置くためのリポジトリです。

- `ads.txt` … AdSense の販売者情報
- `index.html` … https://keisan-tools-lab.github.io/ を開いた人を、くらし計算帖（/kurashi-keisan/）へ移動させるページ

サイト本体は https://github.com/keisan-tools-lab/kurashi-keisan にあります。
